# Tableau du coach

Application web pour dessiner, animer et classer ses systèmes de basket.
HTML/CSS/JS sans dépendance, hébergée sur GitHub Pages, installable sur iPhone et iPad (Partager → Sur l'écran d'accueil) et utilisable hors connexion.

- Bibliothèque par saison, équipe et série, avec recherche
- Éditeur demi-terrain : attaquants 1 à 5, défenseurs x1 à x5, ballon, plots
- Course, dribble, passe, écran, replacement d'un joueur à chaque étape
- Animation étape par étape (vitesse, boucle, curseur)
- Fiches d'entraînement (exercices, durées, horaires), colloques et scouting (joueurs clés, défense, systèmes adverses), où l'on envoie les schémas
- Impression ou PDF d'une fiche
- Export et import des systèmes et des fiches en fichier JSON (sauvegarde, changement d'appareil)

Les données sont enregistrées dans le navigateur de l'appareil. Pense à exporter régulièrement.
